# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a busy student with limited cooking time, I want to generate quick recipes using my near-expiry cooked rice and leftover chicken, so that I can prepare a fresh dinner in under 20 minutes without wasting food.
2. As a health-conscious home cook, I want the system to warn me if I input a leftover item that is no longer safe to consume, so that I do not accidentally prepare unsafe food.
3. As a budget-focused household manager, I want recipe suggestions that rely strictly on what is in my fridge and basic pantry staples, so that I do not have to buy extra specialty ingredients at the grocery store.
